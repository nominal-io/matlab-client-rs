# Nominal for MATLAB

A MATLAB client for [Nominal](https://nominal.io), built on the Nominal Rust SDK.

```matlab
addpath('matlab')

c  = nominal.Client.fromProfile();
a  = c.getOrCreateAsset("<asset name>");
ds = a.getOrCreateDataset("<dataset name>");

ds.write(["<channel 1>" "<channel 2>"], t, V);   % one column of V per channel
tt = ds.fetch("<channel 1>", t0, t1);            % a timetable
```

## Layout

```
crates/ffi/                     Rust: the Nominal SDK behind a C ABI
├── src/                        one module per resource kind
└── include/nominal_ffi.h       generated by cbindgen — `just header`

tools/lintmatlab.m              MATLAB static analysis — `just lint-matlab`

matlab/
├── build.m                     compile the gateway
├── examples/                   runnable demos, nominalexample_*
├── tests/                      nominaltest_smoketest.m — offline, no network
├── src/nominalmex.c            single MEX gateway; all commands dispatch here
└── +nominal/
    ├── Resource.m              handle ownership, destructors, display
    ├── Client.m  Asset.m  Dataset.m  Run.m
    ├── Stream.m  Channel.m  Event.m  ChannelMetadata.m  IngestJob.m
    ├── now.m  toNanos.m  toNanosVector.m  fromNanos.m
    ├── shutdown.m
    └── private/
        ├── nominalmex.mexw64   gateway + Rust library, in one binary
        ├── readProfile.m       ~/.config/nominal/config.yml
        └── structsToTable.m    listing -> table, shared by the classes
```

`nominalmex` is private on purpose. It does no argument checking, so call the
classes, not the gateway.

## Requirements

MATLAB R2021a or newer, on Windows x86-64, Apple silicon or Linux x86-64. See
[BUILDING.md](BUILDING.md) to build it.

## Status

All three platforms have run the full demo suite against a live deployment:
Windows x86-64 (MSVC), Apple silicon (clang) and Linux x86-64 (gcc). Every
build so far used MATLAB R2026a.

- `just lint` runs clippy and MATLAB's `checkcode`.
- `just test` runs the Rust suite.
- `just mex-test` runs the offline MATLAB smoke test.
